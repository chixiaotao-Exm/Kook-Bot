# 中文菜单机器人

独立的 KOOK 中文点餐服务员，在配置的文字频道回复 Gran Furama 菜单、核对中西文菜名并计算美元金额。可接入 gpt-6-astra 理解自然语言点餐及推荐；独立部署于现有音乐、额度、运维和讨论服务之外。

- 发送 `菜单`：一条图文消息，按顺序显示全部 8 页图片，点击图片可查看原图。
- 发送 `菜单 1` 至 `菜单 8`：仅回复指定页。
- 图片已经包含套餐、饮品和两组单点菜单，保留原编号、价格与不确定译名说明。所有已标价格均以美元（USD）结算。菜单两组独立编号，未标价不代表免费，供应情况请向餐厅确认。

内容来自已有“整理成中文版”任务的八页译本，已核对图片尺寸与 SHA256；可复制文字见 [菜单原文](assets/menu-source.md)。静态菜单不会自行更新餐厅价格。

## 中文点餐与 AI 服务员

- 直接发送 `春卷2份，矿泉水2瓶`：返回中文菜名、原西班牙语、单价、数量及合计 `$10.00`。
- 发 `搜索鱼`、`搜索鸡肉`、`有哪些鱼` 或 `搜索 pescado`：直接在双语目录中按菜名和别名匹配，返回菜品编号、中西文名称及美元单价，无须等待 AI。不同菜单中的同名菜保留独立项目，未标价显示“未标价”。
- 搜索每页最多 8 项，内容较长时自动缩短每页条数。发送 `搜索鱼 第2页` 查看后续结果；搜索只列菜品，不计订单合计。中文“鱼”也会匹配名称中的“鱿鱼”。
- 支持 `我要两份春卷`、`两份春卷` 和 `m1:1 2份`。发送 `服务员` 或 `点餐` 查看用法。
- 同名菜有多个版本时列出选项，例如 `蚝油牛肉`，需按回复中的 `m1:编号` / `m2:编号` 指定。两组菜单独立编号，不默认选择较便宜的版本。
- 原菜单未标价或译名不确定的项目列为待确认，不按零元计算；回复的“已知小计”不包含这些项目。
- 配置 AI 后可发送 `能来两份春卷和三瓶矿泉水吗` 或 `两个人吃，推荐两道菜`。复杂请求会先提示正在处理，最多等待约 65 秒；模型异常时可继续用完整菜名直接核价。
- gpt-6-astra 只帮助识别和推荐。实际点餐需完整引用用户原文片段，再由本地程序解析菜名与数量；AI 不得改价、跳过同名确认或遗漏菜品。推荐清单会明确标记为建议，价格和合计全部从目录查得并以整数美分计算。
- 每条消息单独核算，不累计购物车，不向餐厅提交订单。每次最多 12 项、800 字；较长明细会提示拆分。未记载的食材、过敏原、供应和特殊分量需向店家确认。

双语目录为 `assets/catalog-basic.json` 和 `assets/catalog-extended.json`，共 272 项（89 + 154 道编号菜、19 款饮品、10 个套餐），其中 184 项有标价。西语按原始六张菜单照片转录，`source` 对应原图序号；饮品及两个未编号套餐使用应用内编号。`uncertain` 项保留原文歧义。更改价格时须同时更新图片、中文文本及双语目录。

## 内置计算器

- 发送 `计算器` 或 `计算`：查看用法。
- 发送 `计算 12+14×2`：返回 `40`；发送 `计算 (12+18)÷3`：返回 `10`。
- 支持小数、加减乘除和括号。菜单金额以美元（USD）为单位，不输入 `$` 或其他货币符号，不提供汇率换算。小数精确参与运算，结果最多显示 12 位小数，舍入时标记为 `≈`。
- 没有“计算”前缀的算式不会进入计算器。计算、点餐与菜单分别限频（每用户、每频道计算／点餐 3 秒，菜单 10 秒，所有请求至少间隔 1 秒）。表达式不落盘、不写日志，机器人和非配置频道无法触发。

## 部署

需要 Node.js 22.16+，没有第三方运行依赖。

```bash
cd menu-bot
cp .env.example .env
# 填写新机器人的 Token 和文字频道数字 ID，再邀请机器人加入服务器。
# 自然语言点餐需配置 OPENAI_BASE_URL、OPENAI_API_KEY，模型固定为 gpt-6-astra。
npm test
npm start
```

`.env`、`data/` 不入库。`assets/menu.json` 指定图片顺序、标题、尺寸与摘要；更新图片时一并更新摘要。进程以独立低权限用户运行，systemd 示例见 `deploy/kook-menu-bot.service`，健康接口默认仅监听 `127.0.0.1:18995/health`。

只处理授权频道的人类消息，菜单与计算优先，其他文本交给服务员。使用持久收据避免断线重放重复回复，并限制短时间重复请求。上传图片在进程内缓存，发送消息结果不明确时不盲目重发；用户可稍后发送一条新的请求。AI 输入只包含当前一条消息和菜单目录，不共享其他用户上下文，不落盘或写入日志；请求设置 `store:false`。健康接口不输出 Token 或用户消息内容，`bot.waiter` 显示模型配置和最近 AI 请求结果。

测试使用本地图片及模拟 KOOK，不会发送真实消息。菜单模块已加入 CI 和可信代码执行器的项目清单。
