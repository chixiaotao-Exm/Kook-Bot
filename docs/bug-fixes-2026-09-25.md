# 全机器人审计修复

本次修复 2026-09-25 复查中的 12 项问题。各服务的私有配置、账号、Cookie、播放数据和发送账本不随源码提交。

| 范围 | 修复行为 |
| --- | --- |
| 运维健康 | 消息在线和语音/播放健康分别记录；断音或音源异常会告警，网页和汇总不会误报正常播放。过期/未知样本保持待确认，主动停用忽略旧断连诊断。 |
| 系统服务 | 常驻服务要求 active/running 且有效 PID；active/exited 不再被后端改判为正常。 |
| 音乐停止 | 退出未确认时保存独立待退出目标，停止音频并明确提示，有限重试；新连接先解决旧清理，旧重试不能退出新频道。 |
| 音乐加入 | 网页频道请求携带操作代次，排队和查询期间已失效的请求不能撤销新的停止。 |
| QQ 歌单 | 详情预览复用 provider 的统一 ID 校验，接受合法 19 位歌单 ID。 |
| 代码任务 | 明确可恢复的模型网络错误有限重试；耗尽后保留同一任务、补丁与工具上下文暂停，继续不另建空任务。跨进程中断明确提示恢复限制。 |
| 完整检查 | 受信任项目注册表覆盖六项目，运维包含 Node/Python；检查证据记录协议和覆盖范围，旧镜像或旧四项目证据不能通过发布校验。 |
| GitHub 通知 | 独立 CI 使用 run ID 与 attempt 去重；持久化有截止，等待入队有上限，存储失败后安全停止并报告异常健康状态。 |
| 额度登录 | 读完正文、等待上游身份结果后重新确认原会话，已退出的迟到登录不能恢复管理员身份。 |
| 播报设置 | 请求体完成、内部队列开始和持久化前重新验证原会话，注销后的排队请求不能修改计划。 |
| 统一导航 | 重启回执继续记录，但用户已切走时不强行跳回事件页，不清空其他页面正在填写的内容。 |

回归测试使用真实实现与模拟外部依赖覆盖异常路径；Linux 隔离验证包含 FFmpeg 和 QQ Python 测试，不向生产频道点歌或调用真实模型。

## 部署约束

- 更新代码 broker 时同时重建受信任检查镜像；旧完整检查证据必须重新检查。
- 恢复旧源码时保留最新播放状态、命令/通知去重记录，不回滚正在使用的账本。退出待确认字段向后兼容现有版本 2 的播放状态。
- CI 去重键升级不重投已经成功的历史事件；旧摘要无法可靠还原 run ID，人工重投旧执行可能产生一次新通知。
