# 额度与运维统一控制台

额度看板与运维中心共用侧栏，包含额度总览、每日趋势、账号健康、Key 用量、定时播报、服务器、网站接口、机器人和事件记录。运维组件使用 Shadow DOM 隔离样式；离开运维区域后暂停其轮询。

部署地址由各服务的私密环境配置提供。例如 `https://api.example.com/quota/` 可作为统一入口，`/ops/` 可配置重定向至 `/quota/#ops-overview`。实际域名、账号数量、备份路径和生产验收记录保存在部署环境中，不随源码发布。

默认管理操作通过 Sub2API 身份验证，两套服务分别保存 HttpOnly Cookie 并验证 CSRF 与请求来源。登录 Token 不持久化在浏览器存储中。任一登录失败时显示可恢复的错误，退出时注销两端会话。

`PUBLIC_MANAGEMENT=true` 是可选的访客管理配置，会允许匿名访客执行页面开放的管理操作。是否启用由部署者决定；程序仍验证服务白名单、请求来源和命令去重。

测试覆盖双端登录/退出、部分失败恢复、访客权限、导航和移动端布局。生产配置、运行数据与发布记录应单独备份；回滚代码时保留最新的发送去重记录。
